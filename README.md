# hxwl-01 社区老人听力康复作业台

面向社区听力师、老人与家属的听力康复作业台：按左右耳安排听辨与方向（声源定位）训练，
按周生成计划、登记每日训练、自动筛出四天未记录的复诊名单。

## 技术栈

React + Vite + TypeScript + CSS（无额外依赖，localStorage 持久化）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5101

## 分层结构（数据 / 规则 / 存储 / 页面分开）

- `src/types.ts`、`src/data/seed.ts`：**数据**。领域模型、固定选项与演示数据，不写计算逻辑。
- `src/data/rules.ts`：**规则**。纯函数，含 ISO 周次、同患者同周计划唯一、
  调整先复制版本+写原因、周进度（双耳分钟两侧各计）、四天未记录进复诊名单、PTA 计算等。
- `src/state/storage.ts`：**存储**。只负责 AppState 在 localStorage 的读写。
- `src/state/store.ts`：粘合层，页面只能通过 actions 改数据。
- `src/ui/*`：**页面**。作业台、复诊名单、档案建档等组件，不直接读写 localStorage。

## 业务规则

- 听力师必须勾选“已核对听力曲线”才能生成新一周计划；同一患者同一年同一周只保留一份计划。
- 调整计划不能覆盖旧版：先整体复制当前版本生成新版本，必须填写调整原因，版本链全部留档。
- 计划记录周次（ISO-8601）、左右耳各自的听辨/方向内容与目标分钟、家属提示方式。
- 患者/家属登记每次训练：日期、耳别（左/右/双耳）、类型、分钟、困难项；双耳训练两侧各计一份。
- 距最近一次登记满 4 天（从未登记则从建档日算）自动进入复诊联系名单，可记录家属联系方式与结果。
- 家属提示方式作为患者偏好跨周保留，生成新计划时自动带入，也可按周修改。
- 数据保存在浏览器 localStorage（`hxwl-rehab-state-v1`），关闭重开后计划、训练、
  联系名单与提示偏好都在；页面提供“重置演示数据”。
