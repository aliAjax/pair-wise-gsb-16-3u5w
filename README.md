# 社区听力康复作业台

面向社区听力康复场景：老人常说不清训练与家属配合情况，本工作台把**按左右耳安排听辨/方向训练、周目标分钟、家属提示方式、训练登记、复诊名单**串成一条线。

## 业务规则

- **周计划**：听力师核对听力曲线后，才能为老人生成新一周计划；计划记录周次、目标分钟数、左右耳的听辨训练与方向辨别训练、家属提示方式。
- **同一患者同一周只保留一份计划**：需要改动时走“调整版本”，系统复制当前版本生成新版本（版本号 +1）并要求填写调整原因，历史版本全部保留。
- **训练登记**：老人或家属登记每次训练的日期、耳朵、类型、分钟与困难项（提供常见困难项快捷标签）。
- **复诊名单**：距最近一次训练登记**满 4 天（含）自动进入**，从未登记也算；补登记后自动移出。联系跟进记录保存在名单内。
- **提示偏好**：家属提示方式（口头提醒/手势/图片卡/示范/便签）作为长期偏好保存在患者档案，每周计划默认带出、可按周覆盖。
- **曲线核对**：听力曲线一旦修改阈值或日期，核对状态自动作废，必须重新核对才能生成计划。
- **重开不丢**：所有数据保存在浏览器 localStorage，重开页面后计划、训练、复诊名单、提示偏好都在；右上角可一键恢复演示数据。

## 分层结构（数据、规则、存储、页面分开）

| 目录 | 职责 |
| --- | --- |
| `src/types.ts`、`src/data/` | 领域模型、字典常量、初始演示数据（数据） |
| `src/rules/` | ISO 周计算、计划生成/调整、曲线核对、复诊判定、进度汇总（纯函数，不碰存储与 DOM） |
| `src/storage/` | localStorage 读写、结构校验、损坏回退、重置 |
| `src/components/`、`src/App.tsx` | 页面与交互，通过规则函数操作数据，不直接访问 localStorage |

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5101。生产构建：`npm run build`。
